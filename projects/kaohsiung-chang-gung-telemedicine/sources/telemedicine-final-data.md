# 1. 專案定位

## 1.1 專案核心

以**高雄長庚紀念醫院**為核心，推動跨院所、偏鄉、離島、衛生所、居家／長照、矯正機關、急診及復健等場域的遠距醫療服務，逐步結合資訊整合、HIS、資料分析、Dashboard
與 AI 輔助工具。

## 1.2 核心故事線

**偏鄉／離島與特殊場域需求** → **建立遠距專科支援** →
**擴大合作院所與服務場域** → **建立排程、會診、申報及管理流程** →
**累積服務成果** → **導入 HIS／Dashboard／自動化** → **朝 AI、FHIR
與跨院資料整合發展**

## 1.3 對外成果敘事

高雄長庚自偏鄉遠距醫療起步，逐步累積跨院所、跨場域及跨專科的服務經驗，並隨制度與給付政策演進，將遠距醫療從單一視訊會診延伸至偏鄉、離島、衛生所、急診、居家／長照及矯正機關等多元場域，形成具區域整合特色的遠距醫療服務模式。

## 4.2 主要服務模式

-   **專科遠距門診**：固定排程，由醫學中心專科支援在地端。

-   **影像與資料協作**：病灶照片、眼底影像及會診紀錄支援判讀。
-   **特殊場域服務**：監所、離島及其他移動受限場域。
